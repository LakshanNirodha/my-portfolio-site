Microsoft Sentinel SOC Lab

Detected · Password Spray

Built a small Security Operations Centre lab on Azure to learn detection engineering hands-on instead of from theory alone. Deployed a Log Analytics workspace, connected it to Microsoft Sentinel, ingested sign-in logs, and wrote an analytic rule to flag unusual authentication patterns. The lab surfaced a simulated password spray attack - repeated low-and-slow sign-in attempts across many accounts from one source - which I investigated and documented like a real incident.
